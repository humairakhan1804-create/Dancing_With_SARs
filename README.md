Dancing with the SARs — NISAR Surface Change Explorer

**An open-source interactive application built for the 2026 NASA Space Apps Challenge.**

## 🌍 Overview
Earth's surface is in constant motion—wetlands expand and contract, forests shrink from wildfires and deforestation, glaciers shift, and land deforms from seismic activity. Because clouds, smoke, and darkness often block traditional optical satellites, tracking these changes in real time is difficult.

This project leverages radar remote sensing data from the **NASA-ISRO Synthetic Aperture Radar (NISAR)** mission to translate complex radar backscatter observations into intuitive, actionable visualizations for scientists, decision-makers, and the public.

## ✨ Key Features
* **Interactive Change-Detection Map:** Compare multi-temporal SAR imagery side-by-side to highlight surface roughness, moisture shifts, and structural changes.
* **Time-Series Analysis:** Track dynamic environmental patterns over multiple time steps.
* **Multi-Layer Context:** Overlay NISAR radar data with optical satellite imagery and GIS boundaries for clearer interpretation.
* **Scientific Insights:** Explains the physical drivers behind observed radar polarizations on land, water, or ice.
